Ceilings that are still compile-time.

A task may occupy 128 capabilities in a cspace of 256 slots. An IPC message is 256 bytes. Eight CPUs. A volume ceiling of 16 GiB, with the real size read from the disk. The task count is provisioned at boot from untyped memory, up to 256. The full table, with the symbol for each ceiling, is docs/LIMITATIONS.md section 3.1.

Work queued for later sessions.

Each item is one concern, written so a later session can take it without re-deriving the reason. The same text is in docs/ROADMAP.md. Do not start a later item while an earlier one in the same lane is open. Do not delete a witness to make room.

  1. 4.17 One stamped kernel image for the default smoke jobs

    Jobs that boot the default kernel should download one image and check its build-flag stamp and its hash. Jobs that pass a different flag keep their own build. A shared image without the stamp is a gate that can pass on the wrong kernel.

  2. 4.20 A constant-time check on the password path and the AEAD

    A call-graph check that those paths use the constant-time compare, and a nightly timing run. This does not close limitation 5.4, and it does not replace the primitives.

  3. 4.22 Clang as a second nightly compiler

    A nightly build with Clang that fails if it cannot link. It does not gate a merge until it has stayed linkable, and a silent skip is a failure.

  4. 4.23 A red nightly opens an issue, and PyYAML is hash-pinned

    The fuzz and Kani control-arm workflows open an issue when they go red. The existing pyyaml==6.0.3 installs gain a hash pin, so a substituted wheel cannot satisfy the version pin.

  5. 4.19 A nightly guest syscall fuzzer

    The existing fuzz targets are parsers in the Rust core. Nothing there calls syscall(). Off the merge path, in the same shape as the nightly fuzz workflow.

  6. 5.4 Execute only from a file capability

    Closes limitation 1.23. A session that can read a file and does not hold EXEC cannot run it.

  7. 5.6 and 5.7 Measured boot and rollback fail closed when a TPM is present

    The default research build may still boot without one, and must say so. A machine with a TPM does not mount an unanchored volume unless the installer recorded that choice.

  8. 5.14 Refuse a bus-master when the IOMMU is off

    A build flag in the shape of MEASURED_BOOT_REQUIRED. The default build keeps today's behaviour, which limitation 2.12 already states. This is not roadmap 2.12, which keeps secrets out of swap.

  9. 5.15 An audit of the cryptography, or a replacement

    A maintainer decision. Do not write new primitives. Limitation 5.4 is the status. The check that can land first is roadmap 4.20.

  10. 5.11 Models of the four protocols that have already raced

    Spawn and teardown, the kernel-stack claim, the TLB shootdown, revocation against lookup. Each model ships with a seeded defect. Needs decision D9.

  11. 5.9 Reclaim only by revoking the untyped capability

    Then, and only then, a ring-3 allocator may reuse the bytes. Limitation 2.5.

  12. 5.10 Bound each grant in the kernel

    One capability per grant, after filesystem phase 2. Needs decision D8. Closes limitation 1.24.

  13. 4.4 and 4.11 Signed releases a third party can rebuild

    SLSA provenance, then verify-release.sh. The four existing releases are unsigned tags.
