Run it

An x86-64 Linux host, its normal compiler, and QEMU. No cross-compiler.

Boot the default image.

$ rustup target add x86_64-unknown-none
$ make
$ make qemu

make smoke builds a clean image and boots to a ring-3 login. make test runs the Rust tests and a clean rebuild. It boots nothing. The capability suite is:

$ make smoke-captest         # 269 capability checks

DEBUG_SHELL defaults off. It is a development keyboard inside the kernel. Do not boot a smoke image that was built with it. docs/BUILDING.md is the full flag list, including every defect flag a control arm uses. The document is held complete by a checker.

The catalogue names every one of the 610 test targets.

TESTS.md is that catalogue. A target that does not exist is a failed check, and so is a document that names one. Run the gate you touched, and its control arm, before you push. A push is a poor way to discover that the arm no longer goes red.

Install onto a disk the kernel can actually write.

IDE, SD and eMMC. The installer asks for a typed confirmation and creates two accounts. Each account's password can open the disk. There are eight key slots. A ninth account does not get one: the change fails and the volume is left as it was.

NVMe and SATA are not install targets. USB keyboards are not supported. A machine with no PS/2 and no serial port is not a machine this build can operate.

If the host has no TPM, the default image will say so and continue. That is the behaviour of the build, not a successful measured boot.
